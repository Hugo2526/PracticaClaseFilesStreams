# Práctica de Streams: Análisis de datos de un centro de salud

##  Descripción del proyecto

Este proyecto consiste en el análisis de datos de pacientes de un centro de salud del Servicio Andaluz de Salud.

A partir de un fichero CSV con 1000 registros de pacientes, se cargan los datos en una lista de objetos Java y se realizan diferentes consultas.

El objetivo principal es practicar el uso de Streams, lectura de ficheros y modelado de datos con Java y Lombok.
